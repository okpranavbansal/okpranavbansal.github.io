A vim-inspired text editor built with raw C and POSIX systems programming. Features full terminal raw mode, scrolling, searching, and file I/O within ~950 lines of code.

Key highlights:
- Implementation of raw terminal I/O and escape sequences.
- Incremental search and status-bar UI.
- Developed as a deep-dive into systems-level C programming.
